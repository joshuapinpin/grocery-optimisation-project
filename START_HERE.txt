☁️ DEPLOY TO AWS - CHOOSE YOUR PATH

Option 1️⃣: AWS Lightsail (Easiest - Recommended for getting started)
├─ Cost: ~$3.50/month
├─ Setup Time: 10 minutes
├─ Simplest option, perfect for small deployments
└─ Run: ./aws-deploy.sh full-setup us-east-1

Option 2️⃣: AWS App Runner (Fastest setup)
├─ Cost: ~$1-5/month
├─ Setup Time: 5 minutes
├─ Auto-deploys from GitHub
└─ Connect GitHub → App Runner → Done!

Option 3️⃣: AWS ECS Fargate (Production-grade)
├─ Cost: ~$90/month
├─ Setup Time: 30 minutes
├─ Highly scalable and flexible
└─ Run: aws cloudformation create-stack ...

Option 4️⃣: AWS Elastic Beanstalk (Alternative)
├─ Cost: ~$50/month
├─ Setup Time: 20 minutes
├─ Good for multi-container apps
└─ Run: eb create bagnsave-env

🔧 USEFUL COMMANDS

Local Development:
  docker-compose up -d          # Start all services
  docker-compose down           # Stop all services

❓ QUESTIONS?

Frontend issues:
  → Check nginx.conf
  → Ensure backend is running
  → View logs: docker-compose logs frontend

Backend issues:
  → Check database connection
  → View logs: docker-compose logs backend
  → Test health: curl http://localhost:8080/api/actuator/health

Database issues:
  → Check it's running: docker-compose ps postgres
  → Test connection: docker-compose exec postgres psql -U bashServiceAccount -d bagnsave_db_v2

AWS issues:
  → Run: ./aws-deploy.sh status us-east-1
  → Check CloudWatch logs in AWS Console
  → See AWS_DEPLOYMENT_GUIDE.md
